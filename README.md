# Spring Boot Student CRUD Application

A simple RESTful backend application built using Spring Boot that performs full CRUD (Create, Read, Update, Delete) operations on Student data using MySQL database.

---

## Features

- Add a new student  
- Get all students  
- Get student by ID  
- Update student details (PATCH)  
- Delete student by ID  

---

## Tech Stack

- Java  
- Spring Boot  
- Spring Data JPA  
- Hibernate  
- MySQL  
- REST API  

---

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /addStudent | Add new student |
| GET | / | Get all students |
| GET | /getStudentById/{id} | Get student by ID |
| PATCH | /updateStudent/{id} | Update student |
| DELETE | /delStudent/{id} | Delete student |
